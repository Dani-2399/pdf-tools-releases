# ClicPDF

Herramientas PDF desde el clic derecho del explorador de Windows, sin subir nada a internet: unir, organizar,
eliminar y extraer páginas, dividir, comprimir, girar, editar, comparar, números de página, firmar, hacer
buscable (OCR), convertir a Word, Excel, PowerPoint y JPG, extraer imágenes, imágenes y documentos de Office a
PDF, recetas y carpetas automáticas, proteger y quitar contraseña.

(Antes se llamaba «PDF Tools».)

Este repositorio solo contiene los **instaladores**. La app busca aquí sus actualizaciones.

## Instalar

1. Abre la última versión en [Releases](../../releases/latest).
2. Descarga el instalador de tu equipo:
   - `ClicPDF_x.y.z_x64-setup.exe` → la mayoría de PC (Intel / AMD).
   - `ClicPDF_x.y.z_arm64-setup.exe` → equipos ARM (p. ej. Surface Pro con Snapdragon).
3. Ejecútalo. Se instala para tu usuario, sin permisos de administrador.

Después, haz clic derecho sobre un PDF (o imágenes, documentos de Word/Excel/PowerPoint o una carpeta) →
**ClicPDF**.

> Windows puede mostrar «Windows protegió su PC» porque el instalador aún no está firmado con un certificado
> de editor: pulsa **Más información → Ejecutar de todas formas**.
